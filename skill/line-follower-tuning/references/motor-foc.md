# 电机层（FOC 双驱）

> 上层再怎么调，电机层不准都是白费。**这一层必须独立验证通过再联调。**

---

## 一分钟判断走哪条路

| 现象 | 先做 |
|---|---|
| 一进 RUN 就飞车到 100+ rad/s，而 `iq` 只有 0.2 A | **零电角度错** ⇒ 发 `Y` 重标（**不要发 `A`**） |
| 完全不转，`iq` 也几乎 0，没有任何命令能解锁 | **NOSENSOR 锁死** ⇒ 发 `Y` 复活 |
| 有电流但不转（`iq` 1.4~1.6 A、`uq` 顶满、编码器计数只微抖） | 编码器偏心 / 读数锁死 / P 太大（按顺序查） |
| 目标下发但慢慢爬，像硬顶住 | `W` 斜率太小 ⇒ 发 `W140` |
| 转起来一顿一顿、周期过零 | 编码器偏心 ⇒ 发 `X` 建补偿表 → 重跑 `Y` |

## 上电必做四件事

```
H1                # 板间串口隔离（单板标定必开，上位机会 20 Hz 灌命令）
Y6,0              # 轴 0：库级 initFOC，自动判方向 + 算零电角度，成功写 NVS
Y6,1              # 轴 1
W140              # 目标斜率 140 rad/s²（默认 5，从 0 到 60 要 12 秒）
K0.1,1.0,0,10.0   # 速度环 P=0.1 / I=1.0 / D=0 / uq 限幅 10 V
```

★ **`Y` 是唯一能让"锁死轴"复活的手段。**
★ **`A` 不判方向**，它是按当前 `dir` 反算 zea 的。猜错 `dir` 再发 `A`
⇒ 3 V/945 mA 硬堵转、只挪 3.6°（电流全在 d 轴，不产生力矩）。
**改 `dir` 之前一定先用 `Y` 让库自己判。**

## 七个真实缺陷（复刻时大概率也会遇到）

### 1. 两个电机抢 LEDC 通道
通道写死 `0/1/2` ⇒ 第二个 driver 实例一创建就占了第一个的。
**修**：按实例分配通道基址（M0 = 0..2，M1 = 3..5）。

### 2. 两个编码器共享 `static` 变量
`getSensorAngle()` 里的 `last_valid` / `initialized` 是**函数内 static**
⇒ 两个实例共享同一份状态，一个轴的跳变污染另一个轴。
**修**：改成成员变量。

### 3. 同一 SPI 外设重复 `begin()`
两个编码器共用 SCK/MISO（只有 CS 不同），各自 `SPIClass(VSPI)` 各自 `begin()` 会打架。
**修**：全局限一次、共享一个 `SPIClass`。

### 4. `ledcAttachPin()` 早于 `ledcSetup()`
报 `E (120) ledc: LEDC is not initialized`。**修**：严格先 setup 后 attach。

### 5. ★ 编码器读数「永久锁死」
一次 SPI 受扰读出 `Δcnt = 8192`（恰好 π，低 13 位不变只翻最高位）的假跳变，
旧逻辑 `if (diff > π && !crossing) return _last_valid;` 且**不更新** `_last_valid`
⇒ 假跳变持续出现 ⇒ 读数永远停在旧值 ⇒ `v ≡ 0`
⇒ 速度环把 `uq` 顶到限幅灌 1.4 A ⇒ **不转**。

**修**：加连续异常计数，最多连丢 2 拍，**第 3 拍无条件接受**。

> **通则：任何"丢弃异常读数"的逻辑都必须有强制接受兜底**，否则一个持续异常就死锁。

### 6. ★ 编码器磁铁偏心
磁铁/芯片偏心 ⇒ 编码器角带**每机械转一次的正弦误差**。
实测机械角振幅 **±19.5°**（= ±136° 电角度）。

- 开环正常（换相角是时间积分，不读编码器）
- 闭环 `elecAngle = norm(dir·pp·θ_enc − zea)` 直接吃进误差
  ⇒ 每转里两次把换相矢量推偏过 ±90° ⇒ 力矩周期过零/反向 ⇒ **电机激荡**

**修**：用开环磁场角当精确时钟测误差，按编码器角分 256 箱取均值、取负作补偿表，
在 `getSensorAngle()` 里加回去，表存 NVS。
标定完**必须重跑 `Y`**（zea 要在补偿后的角度上重算）。

### 7. 速度环 P 不能大
`P = 0.2` 时，35 rad/s 的误差就打满限幅 ⇒ **bang-bang 极限环**。
改 `P = 0.1` 后翻转帧 10→0、`iq` 降 4.5 倍。
**P / I 是实测定案值，不要动。**

## 上电初始化：四级保险

`initFOC()` 失败会把轴**永久锁死**（`dir = UNKNOWN`、`zea` 未设、库内已 `disable()`），
之后速度/力矩命令全被拒绝，开环虽然放行但 `move()` 见 `enabled == 0` 直接 return
⇒ 零 PWM、零电流、零位移，**极易误判成"硬件没电"**，而且没有任何命令能解锁。

```
① 复用 NVS 里的 (dir, zea)   ← 标定过一次就直接用，跳过运动式判方向（完全可复现）
② 真跑 initFOC()
③ 静态兜底                   ← 提高对齐电压 + enable() + 重试一次
④ 存盘
```

★ **第 ① 级最重要**。库里的 `alignSensor()` 靠"转一下看有没有动 0.062 rad"判方向，
这个判定**时好时坏**。只要 `dir` 已知，就完全可以用"静止矢量反算"跳过运动判定
——这才是可复现的做法。

## `iq` 虚高：不要被吓到

固件报 `iq ≈ 1.65 A`，而台面电源（12.02 V / CV 模式）只取 **0.49 A**：

```
固件功率 = 1.5·uq·iq ≈ 13.6 W  >  输入 5.9 W      ← 物理不可能
```

⇒ **`iq` 采样虚高约 2×**，所谓"硬启动过流"是**采样伪报警**。
用 KV 反解：`K_V = 100 rpm/V = 10.47 rad/s/V`，真实电流只有 ~1.0 A。

**修**：采样增益 ×1.8（保守，宁早跳不晚跳），OC 判据改用**滤波后**的 iq，
并把确认计数从 5 提到 10（滤掉开关尖峰）。

## 协议与状态帧

```
入（\n 结尾，大小写不敏感）：
  R<v0>,<v1>   速度模式，设两轴目标角速度 [rad/s]
  T<u0>,<u1>   力矩模式，设两轴目标 Uq [V]
  S            立即停机
  K<p>,<i>[,<d>[,<lim>]]   速度环
  W<n>         目标斜率
  Y[v][,<ax>]  重对齐（复活手段）
  P[v][,<ax>]  实测极对数
  F[sec][,<ax>] 速度反馈体检
  E            打印原始传感器读数（★判编码器必须用它，不能用 A）
  X / X0 / X1 / X? / Xoff   编码器偏心补偿
  L<v>,<ax>    开环转（首次接新电机必做，验相序）
  B[n]         飞行记录仪（查偶发问题）
  H0/H1        板间串口隔离

出（50 ms 一帧，IDLE 时 200 ms 心跳）：
  A<a0>,V<v0>,A1<a1>,V1<v1>,S<c0><c1>,I<i0>
  c = I(IDLE) / R(RUN) / S(STALL) / O(OC)
```

★ **判断"车是不是在动"只看 `vMeas`。** 两轴 IDLE 时 `wL/wR` 是**陈旧缓存**。

## 参数不能凭空改

- `P = 0.1`、`I = 1.0` 是实测定案。改大就 bang-bang。
- `uq` 限幅是**隐形速度天花板**：`uq ≈ dv·v`，限幅 10 V 时 `v_max ≈ 0.85·10/dv`。
  改限幅之前先算这个。
- 极对数用**转子磁钢块数/2**，不是定子槽数（12 个绕组是槽数，不是极对数）。
- 改 `pp` 之后该轴的 `zea` 立即失效，**必须重跑 `Y`**。
