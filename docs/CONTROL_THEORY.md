# 控制理论：把"调参"变成"算"

> 这份文档解释**为什么**参数是这些值。看懂它，你换一台车也能自己推出来。
> 如果你只想让车跑起来，去看 [`TUNING_GUIDE.md`](./TUNING_GUIDE.md)。

---

## 1. 车体运动学

差速小车，`v` 车体线速度、`ω` 偏航率、`Rw` 轮半径、`Lw` 轮距：

```
ωL = (v − ω·Lw/2) / Rw
ωR = (v + ω·Lw/2) / Rw
```

反解（给定轮速求车体运动）：

```
v = (ωL + ωR)·Rw/2
ω = (ωR − ωL)·Rw/Lw
```

本车实测：`Rw = 0.015045 m`（轮径 30.09 mm）、`Lw = 0.144 m`。
⇒ `Lw/2 / Rw = 0.072 / 0.015045 = 4.786`，即**每 1 rad/s 偏航率需要 4.786 rad/s 的轮速差**。

## 2. 位置环：为什么会有一个"必需的稳态偏差"

把巡线看成一个位置伺服：输入是横向偏差 `e`（m），输出是舵量 `turn`（rad/s）。

```
turn = Kp·e + Kd·ė
```

### 2.1 稳态误差（type-0 环节的宿命）

纯 P 环节对**常值输入**有稳态误差，对**斜坡输入**（走圆弧就是位置斜坡）误差更大且恒定：

```
圆弧上所需的偏航率   ω_req = v / R
所需舵量            turn_req = ω_req / 执行增益 = (v/R) / 0.9007
维持它需要的偏差     e_req = turn_req / Kp
```

代入本车实测参数（**七路灰度视场只有 ±40 mm**）：

| 弧 | R | v | `ω_req` | `turn_req` | `e_req` | 占视场 |
|---|---|---|---|---|---|---|
| R500 | 0.500 | 0.50 | 1.00 | 1.11 | 20.6 mm | 52% |
| R685 | 0.685 | 0.60 | 0.88 | 0.97 | 18.0 mm | 45% |
| R342 | 0.342 | 0.42 | 1.23 | 1.36 | 25.2 mm | 63% |
| **R292** | 0.292 | 0.42 | 1.44 | 1.60 | **29.6 mm** | **74%** |
| R392 | 0.392 | 0.52 | 1.33 | 1.47 | 27.3 mm | 68% |

> **结论：光"待在圆弧上"就要吃掉 45%~74% 的视场。**
> 剩给扰动的余量不到 10 mm，而量化台阶就是 6.7 mm ⇒ 一个台阶就出界。

**这就是"直道幅度为 0、弧内幅度 30~36 mm"的全部原因。**
不是增益没调好，是**几何上的必然**。

### 2.2 两个方向都堵死

| 动作 | 好处 | 代价 |
|---|---|---|
| `Kp` ↑ | `e_req` ↓ | `ζ ∝ 1/√Kp` 恶化；且 `e = 40 mm` 时 `Kp·0.040` 直接超舵量限幅 ⇒ **bang-bang** |
| `Kp` ↓ | ζ 好一点 | `e_req` ↑，更靠视场边界 |
| `Kd` ↑ | ζ ↑ | **有硬上限**：6.7 mm 台阶的差商尖峰会把环路打死（本车 Kd > 12 就死） |

**⇒ 唯一出路是前馈**（见第 3 节）。

## 3. 前馈：把常值舵量直接欠出去

### 3.1 稳态值可以直接算

圆弧稳态时，实际偏航率必然等于 `v/R`。所以"维持这段曲率所需的舵量"就是：

```
arcff = sgn · (v / R) / 执行增益
```

本车执行增益实测 **0.9007**（发 `w` 阶跃读 `GyroZ` 得到的）。

**但不要钉满**。钉 `0.90·(v/R)`（而不是 `(v/R)/0.9007`）意味着前馈只出 **81%**，
剩下的 **19% 刻意留给位置环**（对应 `e ≈ 3~6 mm`）。
钉满会让位置环空转、彻底失去纠偏能力。

```
弧内：  turn = Kp·e + Kd·ė + 0.90·(v/R)
                └── 19% ──┘   └── 81% ──┘
```

位置环的负担从 100% 降到 19% ⇒ 视场余量从 10~15 mm 涨到 **30 mm 以上**。
**不动速度、不动 Kp、不动 Kd。**

### 3.2 为什么"学习"这条路走不通

如果靠观测 `GyroZ` 慢学进 `arcff`（低通 0.25 s + 跟踪 0.20 s ≈ **0.45 s 滞后**），
有两个致命问题：

1. **弯的头 0.45 s 前馈是 0**，而这段恰好是入弯瞬态最需要它的时候；
2. **学习链通常有门限**（比如"只在 `|e| < 27 mm` 时才学"），而缺前馈时 `e` 必然冲过 27 mm
   ⇒ **学习被冻结** ⇒ 前馈永远学不上来。**它在最需要它的时候恰好失效。**

所以：**别学，直接算。** 前馈是"路段属性"，不是"需要辨识的参数"。

## 4. 阻尼比：只用标度关系，不要信绝对值

把位置环 + 偏航率环串起来。设偏航率环为

```
ω_cmd = a · turn − b · GyroZ          （本车 a = 1.6, b = 0.6）
```

只保留位置反馈部分（`turn = Kp·y + Kd·ẏ`，`y` 为横向偏差，`ẏ = v·ψ`）：

```
ÿ + a·Kd·v·ẏ + a·Kp·v·y = 0
```

⇒

```
ωn = √(a·Kp·v)
ζ  = (Kd/2) · √(a·v / Kp)
```

### 4.1 三条可直接用的标度律

| 改变 | 对 ζ | 对 ωn |
|---|---|---|
| `v` ↑ | **ζ ∝ √v** | `ωn ∝ √v` |
| `Kd` ↑ | **ζ ∝ Kd**（线性） | 不变 |
| `Kp` ↑ | **ζ ∝ 1/√Kp** | `ωn ∝ √Kp` |

> ⚠️ **代入本车参数（Kp=54, Kd=12, a=1.6, v=0.70）算出来 ζ ≈ 0.86，
> 但实测行为对应的等效 ζ 只有 0.5 左右。**
> 差额来自量化（6.7 mm 台阶）、执行饱和（舵量限幅）、前视延迟（66/v 秒）。
>
> **所以不要把 ζ 当绝对值用，只用它的标度关系做趋势判断。**

### 4.2 关键推论：不能靠降速加阻尼

`ζ ∝ √v` ⇒ **降速让阻尼比下降**，同时 `ωn ∝ √v` 让周期变长、单次摆幅更大。
这一条被实车验证过：弯道速度全降 15%，结果"跑得更差了"。

### 4.3 `Kp` 必须严格 ∝ v

如果 `Kp ∝ v`，则 `ζ ∝ √v/√v = 常数` —— **阻尼比与速度无关**。
如果只提 `v` 不提 `Kp`，则 `ζ ∝ 1/√v` ⇒ **一提速就摆**。

```
Kp = 24 · v / 0.28
Kd = 9  · √(v / 0.28)      （Kd 用 √ 是为了不要撞上量化尖峰上限）
```

这就是为什么"提速"从来不是改一个数的事。

## 5. 舵量预算：三层限幅，顺序不能错

```
wCap = min(
   13.889 · (v − 0.15045),          // ① 内轮不落进静摩擦死区
   (wheelMax·Rw − v_指令) / 0.072,  // ② 外轮不饱和
   yawMax = 4.0                     // ③ 机械/安全上限
)
turn = constrain(turn, ±lineTurnMax = 2.00)
```

### ① 内轮死区（0.15045 = `wDipMin · Rw` = 10 × 0.015045）

偏航率环在打滑时会与实测**反号** ⇒ 自我放大：内轮掉进静摩擦死区不转 ⇒
车真的绕内轮枢轴转 ⇒ `GyroZ` 更反向 ⇒ 舵量更负。**实测跑到过 17.8 圈。**

钳住"内轮速 ≥ `wDipMin`"就切断这条正反馈。代价是打滑时实际转弯半径比命令值大。

### ② 外轮饱和

```
外轮轮速 = v/Rw + ω·Lw/(2Rw)
```

`wheelMax = 60 rad/s` = 0.9027 m/s。当 `v = 0.92 m/s` 时，**直行的基础轮速就已经
61.15 rad/s**（贴顶）⇒ 只剩内轮可以动 ⇒ **单向转向** ⇒ 锯齿摆。
**0.92 m/s 永远不要再试。**

可执行舵量：`w_max = (wheelMax·Rw − v) / 0.072`
⇒ 60 rad/s 时 `v = 0.70` 只有 **0.87 rad/s**（而 10 mm 偏差就需要 1.02）。
这就是"隐形天花板"：它在替你压增益。

★ 第 ② 项**必须用指令速度**，不能用 `max(指令, 实测)`：
降速刚写入时实测速度还高，用 max 会把舵量锁死（过渡期算成 0.87，而进弯需要 1.5+）。

### ③ `lineTurnMax = 2.00` 隐含最小可跑半径

```
R_min = v / lineTurnMax
```

`v = 0.28` ⇒ `R_min = 140 mm`（够跑 R200）；`v = 0.40` ⇒ 200 mm（刚好跑 R200，没余量）。
**这也是为什么六段 R200 只能用 0.28。**

## 6. 电压预算：真正的速度天花板

转向靠差速，**外轮需要额外轮速 = 额外电压**。

从电机常数估算：`KV = 100 rpm/V = 10.47 rad/s/V`。
轮速 `ω_wheel = v/Rw = 66.5·v rad/s` ⇒ 反电动势 `= 66.5v/10.47 = 6.35·v` V。
实测含 IR 压降后约 **`uq ≈ 10.4·v`**（0.84 m/s 实测 8.74 V）。

| v | `uq` | 剩余（限幅 10.0 V） | 可执行舵量 |
|---|---|---|---|
| 0.70 | 7.28 V | 2.72 V | 1.54 rad/s（占比 54%） |
| 0.84 | 8.74 V | 1.26 V | 0.93 rad/s |
| **0.86** | ~8.94 V | ~1.06 V | **上限** |
| 0.90 | 9.36 V | 0.64 V | 已被电压限住 |

> ★ **"跑了一段时间才开始摆"是电压特征**，不是热漂移：
> 满电 12.6 V 时勉强有 0.26 V 余量，掉到 11.5 V 以下就归零。

## 7. 量化噪声：为什么用限幅而不是低通

位置分辨率 = 探头间距 = **6.7 mm**。差商算 `ė`：

```
ė_noise ≈ 6.7 mm / 5 ms = 1.34 m/s
```

而真实横向速度物理上不超过 `0.36·v`（0.70 m/s 时 0.25 m/s）
⇒ **噪声比信号大 4~9 倍**。

**低通能压噪，但会吃掉 D 项的相位**：
`ė` 低通 260 ms 时，`ωn ≈ 6 rad/s` 处 D 的净超前只剩 +23°
⇒ 阻尼只能兑现 `sin 23° = 0.39` ⇒ 标称 ζ 0.88 实际 0.34。

**限幅能压噪且零相位**：

```c
float edotMax = base * (v / v_nominal);      // ★必须按速度缩放
lineEDot = constrain(raw, -edotMax, edotMax);
```

为什么必须按速度缩放：固定限幅 `X` 隐含钳位角 `sinθ = X/v`。
`X = 0.25` 时 0.70 m/s ⇒ 20.9°，0.86 m/s ⇒ **16.9°**
⇒ 摆幅只要超过 ±20 mm 就把 D 钳死，而 P 还在长 ⇒ 等效相位滞后 ⇒ 阻尼塌陷。
