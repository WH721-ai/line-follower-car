# 赛道几何与里程表

`field_track_named.geom` 是赛道的**纯文本线框描述**，带每段的命名标注。
固件里所有基于里程的判据（转角授权、四圆区武装、终点停车）都按这份文件的**累计里程**写死。

> ★ **换赛道时，唯一必须改的就是这张表对应的那些宏**。
> 拿到新图纸 → 改 `.geom` → 跑一次 `_map_len.py` → 把新数字抄进固件。

---

## 文件格式

```
# L1 直线段（命名）
LINE  x1  y1  x2  y2            # 单位 mm
# R7 圆弧段
ARC   cx  cy  r  a1  a2         # 圆心 / 半径 / 起止角（度，逆时针为正）
# R19 圆弧段（长度1425）
ARC   2550 4800 300 0 -180
# A1 原地转 +90
```

- 原地转角（A1~A5）**不占里程**，只是一条注释标记。
- 计算脚本：`line-following/tools/_map_len.py`（自动定位本目录的 `.geom`）

```bash
cd line-following/tools
python _map_len.py
```

## 三个必须知道的几何事实

### 1. L12 与 L1 是同一条直线

两段都是 `y = 4800`，起点终点完全重合。所以

> **终点没有任何横线标记，灰度判不出"到头了"。**

这就是为什么终点必须按里程停（`LINE_STOP_ODO_MM`），而不是找横线。
也是为什么"车最后冲出赛道"这个现象一直存在——它并非没停，而是已经跑过终点却没有任何东西让代码知道该停。

### 2. A2 和 A3 只隔 283 mm

连续两个 90° 原地转，中间只有 283 mm。转角流程是
「前进 `L_f = 66 mm` → 原地转 → 重新找线」，两个转角总共要吃掉 132 mm 的前进距离，
**只剩 151 mm 给车回正**。

> 所以这段必须以 **0.25 m/s** 进，速度快一点就会带着动量越过转角点，
> 原地转时轮轴已经偏出去 100 mm 以上，转完必出赛道。

### 3. 段二有两个十字，但没有直角

| 位置 | 事实 |
|---|---|
| L7 × L8 ≈ 14.28 m | 过去之后**仅 490 mm** 就是 R10（R292 的 90° 小弯） |
| L8 上 ≈ 17.07 m | — |

**十字的灰度签名与直角完全相同**（线在车底横过来 ⇒ 整条阵列压白）。
如果不屏蔽，横边检测必然命中 ⇒ 误转 90° ⇒ 再也对不准 R10 的入口。
所以段二必须 `seg2NoCorner = true`，禁用一切转角判据。

## 换赛道怎么做

1. 按你的图纸写一份新的 `.geom`（格式见上）；
2. 跑 `python _map_len.py` 拿到逐段累计里程；
3. 依次改这些宏（都在 `line-following/src/main.cpp`）：

| 宏 / 变量 | 含义 |
|---|---|
| `LINE_CORNER_MM[5]` | 5 个原地转角的里程 |
| `LINE_CORNER_TOL` | 授权窗口半宽（当前 ±1300 mm） |
| `lineV2Odo` | 提档里程门限（当前 6700） |
| `C4_ARM_ODO_LO` | 四圆区武装的里程下限 |
| `C4_ODO_BAIL` | 四圆区兜底撤离里程 |
| `LINE_STOP_ODO_MM` | 终点停车里程 |
| `segPidIndex()` | 按里程查该用哪一组增益 |

4. **实际跑一趟取数据校准**：`odo` 有 −2~−3.5% 的负漂移，
   终点那个数一定要按实测调（停早了调大、停晚了调小）。
